# Lumière — онлайн-запись в салон красоты

Одностраничное приложение на React + Tailwind CSS + Lucide (анимации — Framer Motion).
Работает полностью на локальном состоянии — сервер и база данных не нужны.

## Запуск

```bash
cd lumiere
npm install
npm run dev      # запись: http://localhost:5173/  ·  панель: http://localhost:5173/admin/
```

Продакшен-сборка: `npm run build` → папка `dist/` (открывается с любого статического хостинга).
Публикация на GitHub Pages: `npm run publish` — собирает и копирует результат в `../docs/lumiere/`.

## Веб-приложение (PWA)

Опубликовано: **https://mmipoilo465-a11y.github.io/Default/lumiere/** (панель — `…/lumiere/admin/`)

- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».
- **Android / Chrome / Edge на компьютере:** кнопка «Установить» в плашке под шапкой или меню браузера → «Установить приложение».

После установки Lumière открывается как отдельное приложение без панели браузера, со своей иконкой
и ярлыками (долгое нажатие на иконку на Android): у панели — «Данные и выручка» / «Расписание на день».
Service worker кэширует все файлы — приложение работает без интернета, а после публикации новой версии
обновляется само при следующем запуске с сетью.

## Две страницы

| Страница | Адрес | Для кого |
|---|---|---|
| Онлайн-запись | `/lumiere/` | Посетители: только запись, никаких ссылок на админку |
| Панель руководителя | `/lumiere/admin/` | Владелец: вход по паролю |

Это два отдельных входа сборки (`index.html` и `admin/index.html`): код панели, экран входа
и хэш пароля в файлы страницы записи не попадают. У каждой страницы свой манифест и иконка,
поэтому на телефон их можно установить как два разных приложения («Lumière» и «Lumière Админ»).

**Посетитель** — пошаговая запись: услуга (стрижка / укладка / окрашивание) → мастер (или «любой свободный») →
дата и время (только реально свободные окна с учётом длительности услуги) → контакты →
экран подтверждения с деталями и экспортом в календарь (.ics).

**Руководитель** — две вкладки:
- **Данные и выручка:** выручка сегодня и за 7 дней, средний чек, загрузка; график выручки по дням
  (с подсказками и табличным видом); выручка по направлениям, мастерам и топ-5 услуг;
  список всех предстоящих записей с поиском, фильтром по мастеру и отменой.
- **Расписание на день:** выбор дня из ближайшей недели, сетка свободных и занятых окон по мастерам,
  список записей дня с итогом выручки.

Запись, сделанная на странице посетителя, сразу появляется в открытой панели (даже в соседней вкладке) с меткой «онлайн».

## Доступ руководителя

- Пароль хранится в `src/config/admin.ts` только в виде хэша PBKDF2-SHA256 (210 000 итераций, случайная соль).
- Сменить пароль: `npm run admin:password -- "новый-пароль"`, затем `npm run publish`. Все прежние входы сбрасываются.
- «Запомнить на этом устройстве» — вход на 30 дней, иначе до закрытия вкладки. Кнопка «Выйти» — в шапке панели.
- После 5 неверных попыток ввод блокируется на 30 секунд.

Ограничение: это статический сайт без сервера, поэтому пароль проверяется в браузере.
Панель закрыта от посетителей, но это не замена серверной авторизации: записи хранятся
на каждом устройстве отдельно. Для общей базы записей на всех устройствах нужен бэкенд с авторизацией.

## Данные

Демо-занятость генерируется детерминированно на неделю вперёд (`src/data/seed.ts`).
Состояние хранится в React-контексте (`src/store/AppStore.tsx`) и дублируется в LocalStorage,
чтобы записи не терялись при перезагрузке. Кнопка «Сбросить демо-данные» в панели возвращает исходное состояние.

## Структура

```
index.html         страница записи (вход сборки «visitor»)
admin/index.html   панель руководителя (вход сборки «admin»)
src/
  visitor/     приложение посетителя
  admin/       приложение руководителя: вход по паролю + панель
  bootstrap.tsx  общий запуск: провайдеры состояния, service worker
  data/        каталог услуг и мастеров, генератор демо-записей
  lib/         типы, время, расчёт свободных окон, авторизация
  store/       состояние (с синхронизацией между вкладками) и уведомления
  components/  шапка, подвал, модальное окно, плашка установки, базовые UI-элементы
  features/
    booking/   мастер записи: шаги, сводка, экран подтверждения
    admin/     вкладки панели: метрики, графики выручки, расписание, списки записей
```

Цвета бренда: глубокий фиолетовый `#5B3FA8` (`violet-600`) и мягкий персиковый `#FFC498` (`peach-300`) — `tailwind.config.js`.
