# Lumière — онлайн-запись в салон красоты

Одностраничное приложение на React + Tailwind CSS + Lucide (анимации — Framer Motion).
Работает полностью на локальном состоянии — сервер и база данных не нужны.

## Запуск

```bash
cd lumiere
npm install
npm run dev      # http://localhost:5173
```

Продакшен-сборка: `npm run build` → папка `dist/` (открывается с любого статического хостинга).
Публикация на GitHub Pages: `npm run publish` — собирает и копирует результат в `../docs/lumiere/`.

## Веб-приложение (PWA)

Опубликовано: **https://mmipoilo465-a11y.github.io/Default/lumiere/**

- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».
- **Android / Chrome / Edge на компьютере:** кнопка «Установить» в плашке под шапкой или меню браузера → «Установить приложение».

После установки Lumière открывается как отдельное приложение без панели браузера, со своей иконкой
и ярлыками «Записаться» / «Панель руководителя» (долгое нажатие на иконку на Android).
Service worker кэширует все файлы — приложение работает без интернета, а после публикации новой версии
обновляется само при следующем запуске с сетью.

## Что внутри

**Клиент (без регистрации)** — пошаговая запись на одной странице:
услуга (стрижка / укладка / окрашивание) → мастер (или «любой свободный») →
дата и время (показываются только реально свободные окна с учётом длительности услуги) →
контакты (маска телефона, валидация) → экран подтверждения с деталями и экспортом в календарь (.ics).

**Руководитель** — переключатель в шапке (или ссылка `#admin`):
- сводка дня: число записей, выручка, загрузка, предстоящие записи;
- загрузка на 7 дней вперёд (занятые / свободные 30-минутные окна);
- расписание выбранного дня по мастерам: свободно, занято, онлайн-записи, прошедшее время, выходные;
- список всех предстоящих записей с поиском, фильтром по мастеру, карточкой записи и отменой.

Запись, сделанная клиентом, сразу появляется в панели руководителя с меткой «онлайн»,
а отменённая запись освобождает окно для клиентов.

## Данные

Демо-занятость генерируется детерминированно на неделю вперёд (`src/data/seed.ts`).
Состояние хранится в React-контексте (`src/store/AppStore.tsx`) и дублируется в LocalStorage,
чтобы записи не терялись при перезагрузке. Кнопка «Сбросить демо-данные» в панели возвращает исходное состояние.

## Структура

```
src/
  data/        каталог услуг и мастеров, генератор демо-записей
  lib/         типы, работа со временем, расчёт свободных окон
  store/       состояние приложения и уведомления
  components/  шапка с переключателем режимов, модальное окно, базовые UI-элементы
  features/
    booking/   мастер записи: шаги, сводка, экран подтверждения
    admin/     панель руководителя: метрики, неделя, расписание, список записей
```

Цвета бренда: глубокий фиолетовый `#5B3FA8` (`violet-600`) и мягкий персиковый `#FFC498` (`peach-300`) — `tailwind.config.js`.
