# Atelier — онлайн-запись в салон красоты

Ультра-минималистичное интерактивное демо: клиентский флоу записи + центр управления для администратора.
Все данные живут в `localStorage` (переживают перезагрузку, синхронизируются между вкладками).

```bash
cd salon
npm install
npm run dev        # http://localhost:5173  (админка: #/admin)
npm run build      # production-сборка в dist/ (base: './' — работает из любой папки)
```

**Стек:** React 18 + TypeScript (strict) · Vite 5 · Tailwind CSS 3 (dark mode `class`) · Framer Motion 11 · Lucide React.
**Акцент:** один цвет — глубокий изумруд `#097969` (`accent-*` в `tailwind.config.js`), всё остальное — slate-монохром.

## Ключевые решения

- **Реальная занятость.** Слоты считаются из записей мастера с учётом суммарной длительности услуг, рабочих часов и выходных; на сегодня — с запасом 30 минут от текущего времени.
- **«Любой мастер».** Показывает объединение окон всех подходящих мастеров; при подтверждении назначается свободный мастер с наименьшей загрузкой в этот день — расписание заполняется равномерно.
- **Совместимость услуг.** В одну запись можно добавить только услуги, которые выполнит один мастер; остальные помечаются «отдельной записью».
- **Защита от гонок.** Перед созданием записи слот перепроверяется; если его заняли (например, в соседней вкладке), клиент возвращается к выбору времени.
- **Живое демо.** Мок-данные генерируются детерминированно относительно текущей даты; на следующий день фон перегенерируется, а записи пользователя сохраняются. Кнопка ↺ в панели сбрасывает демо.
