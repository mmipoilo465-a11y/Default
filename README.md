# Вайб-Трекер Привычек 2.0

Геймифицированный трекер привычек: XP, HP, уровни, магазин наград, аналитика, корреляции и прогнозы.

- `vibe-tracker.html` — единственный исходник (он же публикуется как артефакт Claude).
- `docs/` — собранная PWA-версия, которую можно установить на главный экран телефона и использовать офлайн.

## Установка на телефон

Приложение раздаётся через GitHub Pages: **https://mmipoilo465-a11y.github.io/Default/**

- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** открыть ссылку → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

Данные хранятся в браузере телефона (LocalStorage). Перенос между устройствами — через «Данные → Экспорт / Импорт JSON».

## Включить GitHub Pages (один раз)

Settings → Pages → Build and deployment → Source: **Deploy from a branch** →
ветка `claude/habit-tracker-gamified-km2bhh`, папка **/docs** → Save.

## Пересборка после изменений

```bash
npm install
npm run build:pwa   # обновит docs/ и версию кэша service worker
```

## ПДД РФ: Реалистичный Драйв

`pdd-drive.html` — вертикальный 2D-симулятор вождения по ПДД РФ на чистом Canvas (один файл, без зависимостей).
Любое нарушение — «Экзамен не сдан!» со ссылкой на пункт правил.

- 4 авто (седан, хэтчбек, внедорожник, ДПС), 3 локации (Город, Мегаполис, Трасса), 3 уровня сложности.
- Контроль: скорость (+1 км/ч — незачёт), сплошные 1.1/1.3/1.2, автобусные полосы, светофоры, STOP, «Уступи дорогу», помеха справа, трамвай, спецтранспорт, пешеходы (п. 13.1/14.1), поворотники при перестроении/повороте/съезде с кольца, ряд для поворота (п. 8.5), кольцо 4.3.
- Управление: кнопки внизу экрана, **наклон телефона** (кнопка «Наклон»: ровное положение = прямо, мёртвая зона 3°, полный руль при 24°) или клавиатура (стрелки/WASD, Q/E — поворотники, R — D/R).
- Наклон работает только при открытии страницы напрямую в браузере телефона (`docs/pdd/index.html`, на GitHub Pages — `/pdd/`): просмотрщик артефактов claude.ai блокирует датчики движения.
